## 🎮 Como Usar a Apresentação Interativa

Para abrir, basta dar um duplo clique em `Apresentacao_Avaliacao_Diretor_Utilities_Q1_Q2.html` ou abri-lo pelo seu navegador.

### Atalhos de Teclado:
* **`→` (Seta Direita)** ou **`Barra de Espaço`**: Avançar para o próximo slide
* **`←` (Seta Esquerda)**: Voltar ao slide anterior
* **`N`**: Abrir / Fechar a **Gaveta de Notas do Apresentador** (mostra exatamente o que falar em cada slide)
* **`F`**: Entrar / Sair do modo **Tela Cheia (Fullscreen)**
* **`Home` / `End`**: Ir direto para o primeiro ou último slide
* **Botão `🌓 Tema`**: Alterna instantaneamente entre o modo escuro (Dark Tech) e o modo claro (Light Executive).

### Como Exportar para PDF:
1. Abra `Apresentacao_Avaliacao_Diretor_Utilities_Q1_Q2.html` no Chrome ou Safari.
2. Pressione `Cmd + P` (Mac) ou `Ctrl + P` (Windows).
3. No destino da impressora, selecione **"Salvar como PDF"**.
4. Configure a orientação para **Paisagem (Landscape)** e marque a opção **"Gráficos de segundo plano"**.
